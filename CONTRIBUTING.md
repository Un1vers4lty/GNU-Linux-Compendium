# Contributing

First off, thanks for taking the time to contribute! 🙌

## How to Help Out
Right now, you can contribute by:
* Adding or refining distro data inside the `DISTROS/` directory.
* Updating tag categories in `TAGS/`.
* Helping build out the Rust/Tauri matching engine logic.

## Quick Setup
1. Clone the repository:
   ```bash
   git clone [https://github.com/Un1vers4lty/GNU-Linux-Compendium.git](https://github.com/Un1vers4lty/GNU-Linux-Compendium.git)
2. Make sure you have Rust and Tauri prerequisites installed.
3. Run the project locally to test your changes.

## Submitting Changes
 1. Fork the repo and create your feature branch:
    - example: git checkout -b feature/amazing-feature
 4. Commit your changes: git commit -m 'Add amazing new distro YAML'
 5. Push to the branch: git push origin feature/amazing-feature
 6. Open a Pull Request!
